## 調整內容

| 項目 | 調整結果 |
| :--- | :--- |
| 日誌排版 | 維持現有順序，不修改 |
| 新聞 H1 | 改為實際新聞標題 |
| Summary | 改成一般文章導言，不使用引用框 |
| 小編短評 | 獨立 H2，強化閱讀層次 |
| TL;DR | 維持在小編短評之後 |
| 新聞預覽 | 調整標題層級，避免重複摘要 |
| FAQ、Tags | 維持原有機制 |
| NewsImporter | 新新聞的 preview 預設留空，除非和Summary差異超過50% |
