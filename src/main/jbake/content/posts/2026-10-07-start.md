第一步不是先做複雜 CMS，而是建立一個能長久維護的最小結構。即使是靠AI寫，也先弄成我看得快又有插手機會的方式。

## 這次的選擇

網站採用：

| 層次 | 工具 |
|---|---|
| 專案管理 | Maven |
| 靜態網站產生 | JBake |
| 內容 | Markdown |
| 模板 | FreeMarker |
| 發布 | GitHub Pages |

這樣做的核心理由很單純：**文章應該比網站系統本身更重要。**

新增一篇內容，只需要在 `src/main/jbake/content/posts/` 新增 Markdown。

```text
src/main/jbake/
├── assets/
├── content/
│   └── posts/
├── templates/
└── jbake.properties
```

## 視覺原則

好客萌團的綠色不會把整個網站染滿，而是作為互動、狀態與氣氛。

大面積仍以霧白、白色、深炭黑為主；品牌綠主要出現在按鈕、標籤、Hover 與少量背景。

下一步會開始把真正的產品與技術決策放進這裡。
