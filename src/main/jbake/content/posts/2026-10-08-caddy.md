以前都傻傻自己手工換憑證，還常不小心過期沒換到。後來聽說 Nginx 搭配 Certbot 可以自動申請 Let's Encrypt 憑證並自動展期。所以問了AI結果，祂推薦我更無腦的Caddy。

## 最近大人氣的 HTTPS 憑證管理工具

Caddy 是用 Go 語言編寫的開源網頁伺服器（Web Server）與反向代理伺服器（Reverse Proxy），也像 Nginx＋Certbot 會自動向 Let's Encrypt 等受支援的 CA 申請憑證、自動到期前更新憑證，並處理 HTTP 到 HTTPS 的重新導向。但只要寫一行指令就可，看著都覺得好清爽。


```text
www.howqpon.com {
    reverse_proxy springboot:8080
}
```

其實我一口氣設了麾下的10個網站，然後幾秒鐘後憑證都下來了。我都覺得我以前好白癡。
