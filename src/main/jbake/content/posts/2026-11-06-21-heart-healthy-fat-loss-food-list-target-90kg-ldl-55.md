faq1Question=綠茶粉跟一般綠茶差在哪？為什麼我絕對不能吃綠茶粉？
faq1Answer=一般綠茶只是泡出「茶湯」，但綠茶粉是將整片茶葉磨碎吃下肚，含有極高濃度的「維生素 K」。這會直接對抗並削弱你正在服用的抗凝血藥物效力，嚴重威脅心臟支架的安全。請立刻停用綠茶粉，改喝無糖仙草茶或檸檬水最安全。
faq2Question=三色豆（冷凍蔬菜）和薏仁看起來很健康，晚餐水煮可以多吃嗎？
faq2Answer=小心分類陷阱！三色豆裡面的「玉米、青豆仁」，以及薏仁水底下的「薏仁顆粒」，在營養學上都是「澱粉（碳水化合物）」，不是蔬菜。把它們下鍋絕對可以，但必須「等價扣抵」你當天的馬鈴薯或栗子額度，否則熱量與碳水會直接超標，阻礙減重。
faq3Question=發酵的「黃金泡菜」有益生菌，為什麼強烈建議避開？
faq3Answer=為了製造濃郁口感，黃金泡菜的用油、糖、鹽的醬汁裡藏有驚人的鈉，有些廉價製品會用飽和脂肪來創造滑順的口感。想吃益生菌，請堅持吃你原本的「無糖優格」就好，建議最多只能偶爾夾個一兩口當作解饞，不要讓它取代你晚餐「純水煮青菜＋生大蒜＋冷拌好油」的主力防線。

# 🥗 護心減脂食材總表（目標：90kg & LDL降至55）

> 💡 **核心烹調守則：** 全水煮、無鹽/低鈉、起鍋後冷拌好油與無糖果醋。

## 🥩 第一區：低脂高蛋白（建構肌肉、極低飽和脂肪）
- [ ] **義美板豆腐**（日常主力，植物性蛋白）
- [ ] **無糖優格**（早午餐基底，最純淨的發酵益生菌）
- [ ] **鱈魚**（深海魚類，天然 Omega-3）
- [ ] **雞柳條**（極低脂，口感比雞胸軟嫩）
- [ ] **鯛魚片 / 鱸魚片**（無刺、快熟不油膩）
- [ ] **透抽 / 鮮花枝**（幾乎零脂肪，含牛磺酸保護心肌）
- [ ] **豬小里肌 / 腰內肉**（豬肉中最瘦軟的部位）
- [ ] **生豆包**（未油炸的濕豆皮，蛋白質密度高）
- [ ] **茶葉蛋 / 白煮蛋**（優質好吸收，留意茶葉蛋鈉含量，白煮蛋更佳。一天限 1 顆全蛋）
- [ ] *(⚠️ 黃燈限量)*：**起司片**（含飽和脂肪，建議兩天 1 片或暫停）

## 🍠 第二區：超級護心澱粉（穩定血糖、代謝壞膽固醇）
- [ ] **馬鈴薯**（原主力，高鉀排鈉王者）
- [ ] **無調味栗子**（高鉀高纖維，直接替換馬鈴薯或地瓜，下午茶吃 6-8 顆即可）
- [ ] **龍鳳冷凍三色豆**（玉米/青豆仁，請當作「澱粉」與馬鈴薯輪替）
- [ ] **傳統大燕麥片**（非三合一，降 LDL 的王者）
- [ ] **栗子地瓜**（低 GI，高鉀排鈉）
- [ ] **鷹嘴豆 / 雪蓮子**（高蛋白澱粉，地中海護心主力）
- [ ] **蓮藕**（水煮清脆，富含鉀離子穩定血壓）
- [ ] **100% 純蕎麥麵**（想吃麵的唯一解，含蘆丁保護微血管）
- [ ] **薏仁粒**（煮薏仁水底下的顆粒，屬高纖澱粉，需扣抵馬鈴薯額度）

## 🥦 第三區：降脂掃道蔬菜（水溶性纖維主力）
- [ ] **高麗菜 / 金針菇 / 杏鮑菇**（原菜單水煮常客，撐飽胃袋）
- [ ] **紅蘿蔔**（原菜單品項，脂溶性維生素）
- [ ] **秋葵**（黏液是最頂級的水溶性纖維，降脂神器）
- [ ] **新鮮黑木耳 / 白木耳**（血管清道夫，極低熱量）
- [ ] **海帶結 / 海帶根**（抑制腸道吸收脂肪）
- [ ] **筊白筍**（高鉀水分多，自帶甜味）
- [ ] **櫛瓜**（高鉀排鈉，水煮軟脆）
- [ ] **大番茄 / 牛番茄**（茄紅素保護血管內皮）
- [ ] **洋蔥**（強效抗氧化清血管，水煮自帶高湯甜味）
- [ ] *(⚠️ 綠色蔬菜限量)*：**菠菜、青花菜**（因含維生素 K，請適量吃，勿過度單一大量攝取）

## 🍎 第四區：心血管友善水果（早茶與下午茶首選）
- [ ] **芭樂**（神級水果！維生素 C 霸主，極高纖維、低 GI）
- [ ] **香蕉**（原主力，補鉀排鈉，絕佳能量補充）
- [ ] **柑橘**（原主力，果膠豐富，維生素 C 抗氧化）
- [ ] **水梨**（富含水分與果膠，清熱解渴幫助代謝 LDL）
- [ ] **帶皮蘋果**（果膠都在皮上，降 LDL 絕佳）
- [ ] **藍莓**（花青素極大化保護心臟血管）
- [ ] **奇異果**（高維生素 C 與鉀，加速脂肪搬運）
- [ ] **柿子**（富含果膠與β-胡蘿蔔素，糖分略高，一次限 1 顆）

## 🫒 第五區：優質油脂與調味（抗發炎、取代飽和脂肪）
- [ ] **苦茶油**（Omega-9，日常冷拌主力）
- [ ] **亞麻仁油**（Omega-3，日常冷拌主力）
- [ ] **無糖果醋**（零鈉調味神器）
- [ ] **生大蒜**（零鈉提味神隊友。切碎靜置 10 分鐘入醋拌，每日限 1-2 瓣，🚫嚴禁吃大蒜精）
- [ ] **無糖杏仁茶**（液體堅果油，富含維生素 E 護心。需扣抵當餐冷拌油配額，確認無添加澱粉）

## 🍵 第六區：安全飲品（零維生素 K 衝突、零/低咖啡因）
- [ ] **無糖仙草茶**（神級補水：零咖啡因、無維生素 K，高鉀消水腫）
- [ ] **檸檬原汁冰磚 + 白開水**（完美補水，維生素 C 護血管）
- [ ] **無糖薏仁水**（只喝水無負擔，強效排鈉消水腫）
- [ ] **南非國寶茶 / 博士茶**（天生零咖啡因，抗氧化極強）
- [ ] **無糖麥茶 / 黑豆茶**（穀物茶無維生素 K，溫和排鈉）
- [ ] **無糖西西里咖啡**（黑咖啡 + 檸檬，下午提神用）
- [ ] *(限量替代品)*：**無糖紅茶、普洱茶**（發酵茶維生素 K 較低，每日限 1 瓶約 600ml）
- [ ] *(🚫 嚴格禁止)*：**綠茶粉**（維生素 K 濃度極高，直接破壞抗凝血藥效）

## 🥜 第七區：解饞零嘴（高壓期戰備物資）
- [ ] **義美鹹酥黑豆**（替代洋芋片的最強零嘴，下午解饞用，不可當晚餐配菜）
- [ ] **無調味堅果**（一天一小把即可，搭配 B 群吃吸收好）
- [ ] *(⚠️ 黃燈限量)*：**100% 黑巧克力**（含飽和脂肪，降 LDL 期間建議減量）
- [ ] *(🚫 嚴格禁止)*：**起酥蛋糕、市售洋芋片、黃金泡菜**
