faq1Question=綠茶粉跟一般綠茶差在哪？為什麼我絕對不能吃綠茶粉？
faq1Answer=一般綠茶只是泡出「茶湯」，但綠茶粉是將整片茶葉磨碎吃下肚，含有極高濃度的「維生素 K」。這會直接對抗並削弱你正在服用的抗凝血藥物效力，嚴重威脅心臟支架的安全。請立刻停用綠茶粉，改喝無糖仙草茶或檸檬水最安全。
faq2Question=三色豆（冷凍蔬菜）和薏仁看起來很健康，晚餐水煮可以多吃嗎？
faq2Answer=小心分類陷阱！三色豆裡面的「玉米、青豆仁」，以及薏仁水底下的「薏仁顆粒」，在營養學上都是「澱粉（碳水化合物）」，不是蔬菜。把它們下鍋絕對可以，但必須「等價扣抵」你當天的馬鈴薯或栗子額度，否則熱量與碳水會直接超標，阻礙減重。
faq3Question=發酵的「黃金泡菜」有益生菌，為什麼強烈建議避開？
faq3Answer=為了製造濃郁口感，黃金泡菜的用油、糖、鹽的醬汁裡藏有驚人的鈉，有些廉價製品會用飽和脂肪來創造滑順的口感。想吃益生菌，請堅持吃你原本的「無糖優格」就好，建議最多只能偶爾夾個一兩口當作解饞，不要讓它取代你晚餐「純水煮青菜＋生大蒜＋冷拌好油」的主力防線。

## 🥗 護心減脂食材總表（目標：90kg & LDL降至55）

### 🥩 第一區：低脂高蛋白（板豆腐與極瘦肉類）
- [ ] 🧊 義美板豆腐（降 LDL 核心主力，高植物蛋白、零膽固醇，飽足感極佳）
- [ ] 🥛 無糖豆漿 / 無糖黑豆漿（富含植物固醇強效降 LDL。黑豆漿具花青素抗發炎）
- [ ] 🥛 無糖優格 / 無糖優酪乳（補益生菌，需留意乳脂肪。若喝超過 400ml，當日晚餐務必扣抵冷拌油配額）
- [ ] 🐔 雞柳條（極低脂、軟嫩好咬，水煮不柴）
- [ ] 🐟 鯛魚片 / 鱸魚片（極高蛋白，水煮快熟無負擔）
- [ ] 🦑 透抽 / 鮮花枝（幾近零脂，富含牛磺酸保護心肌）
- [ ] 🐷 豬小里肌 / 腰內肉（豬肉最瘦部位，取代五花/梅花肉）
- [ ] 🥟 生豆包 / 濕生豆皮（未油炸，高植物蛋白，吸附果醋口感佳）
- [ ] 🥚 茶葉蛋 / 白煮蛋（優質好吸收，留意茶葉蛋鈉含量，白煮蛋更佳）

### 🍠 第二區：超級護心澱粉（澱粉基底與優質替換品）
- [ ] 🥔 (冰)馬鈴薯（澱粉總司令，帶皮水煮最佳，高鉀排鈉，放涼吃具抗性澱粉）
- [ ] 🌰 無調味栗子（高鉀高纖維，直接替換馬鈴薯或地瓜）
- [ ] 🥣 傳統大燕麥片（非三合一，富含 β-葡聚醣，降 LDL 王者）
- [ ] 🍠 (冰)栗子地瓜（低 GI，高鉀排鈉，口感綿密）
- [ ] 🧆 鷹嘴豆 / 雪蓮子（高蛋白澱粉，地中海護心主力）
- [ ] 🥔 蓮藕（保留清脆口感，穩定血壓）
- [ ] 🍜 100% 純蕎麥麵（富含蘆丁保護微血管，適合做果醋涼麵）
- [ ] 🌽 冷凍三色豆（高纖維優質澱粉，絕非蔬菜，需扣抵馬鈴薯額度）
- [ ] 🥔 山藥（富含黏液蛋白，強效吸附並降低 LDL，高鉀排鈉，水煮熟食）

### 🥦 第三區：降脂掃道蔬菜（水煮極搭，安全避開高維生素 K）
- [ ] 🥒 秋葵（黏液富含水溶性纖維，降膽固醇神器）
- [ ] 🍄 黑木耳 / 白木耳（血管清道夫，零熱量撐飽胃袋）
- [ ] 🌿 海帶結 / 海帶根（海藻酸抑制腸道吸收脂肪，口感 Q 彈）
- [ ] 🎋 筊白筍（極低熱量，高鉀排鈉，自帶天然甜味）
- [ ] 🥒 櫛瓜（低碳水，高鉀，水煮軟脆適口）
- [ ] 🍅 大番茄 / 牛番茄（茄紅素保護血管內皮，釋放天然酸甜高湯味）
- [ ] 🧅 洋蔥（富含槲皮素強效清血管，水煮釋放濃郁甜味代替鹽）

### 🍎 第四區：心血管友善水果（香蕉與柑橘的最佳輪替）
- [ ] 🍎 帶皮蘋果（果膠集中在皮，降 LDL 絕佳下午點心）
- [ ] 🫐 藍莓（超級抗氧化，花青素極大化保護心血管）
- [ ] 🥝 奇異果（高維生素 C 與鉀，加速脂肪搬運，穩定血壓）
- [ ] 🍐 水梨（富含水分與果膠，清甜解渴，代謝壞膽固醇）
- [ ] 🍈 芭樂（減脂護心神果，維生素 C 破表，高纖低糖飽足感極強）
- [ ] 🍅 柿子（富含果膠與 β-胡蘿蔔素，天然糖分較高，每次限吃一顆）
- [ ] 🍌 香蕉（高鉀排鈉神隊友，快速補充能量，糖分較高需注意份量）
- [ ] 🍊 橘子 / 柑橘類（富含維生素 C 與水溶性纖維，保護血管內皮，香蕉的絕佳輪替）

### 🍵 第五區：無負擔水分與機能飲品
- [ ] ☕ 無糖西西里黑咖啡（純黑咖啡＋新鮮檸檬汁。極強抗氧化，嚴禁市售加糖版本，避免三酸甘油酯飆升破壞 LDL 目標）
- [ ] 🫖 南非國寶茶（零咖啡因、零維生素 K，富含抗氧化物，夜晚喝也無負擔的護心神水）
- [ ] 🍵 普洱茶（發酵茶去油解膩，輔助降低 LDL，溫潤不傷胃，留意勿泡太濃）
- [ ] 🌿 無糖仙草茶（零維生素 K、零咖啡因，高鉀排鈉消水腫）
- [ ] 🍋 檸檬原汁冰磚水（零負擔，維生素 C 保護血管壁）
- [ ] 🌾 無糖薏仁水（強效排鈉消水腫。只喝水無負擔；若吃薏仁粒需扣抵澱粉額度）

### 🥑 第六區：優質油脂與調味
- [ ] 🛢️ 苦茶油 / 亞麻仁油（水煮後冷拌，提供 Omega-3/9 幫助抗發炎）
- [ ] 🧄 生大蒜（切碎靜置 10 分鐘，釋放大蒜素降 LDL，每日限 1-2 瓣，不可過量）
- [ ] 🌰 無糖杏仁茶（富含維生素 E 護心血管。需抵扣當餐冷拌油配額，嚴禁含「米粉/澱粉」增稠）


### 🚫 第七區：絕對禁忌黑名單（危及支架與用藥，嚴禁食用）
- [x] ❌ **納豆：** 含有爆表濃度的「維生素 K2」，會直接強烈抵銷抗凝血藥物效力，引發支架血栓致命危機。
- [x] ❌ **綠茶粉 / 抹茶粉：** 將整片茶葉吃下肚，維生素 K 含量極高，同樣會嚴重破壞抗凝血藥物的保護網。
- [x] ❌ **黃金泡菜 / 市售醃漬品：** 隱藏驚人鈉含量與加工植物油，會破壞熱量赤字、引起水分滯留並阻礙 LDL 下降。
